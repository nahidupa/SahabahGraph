  4. Test each scenario below by sending the command to the AI chat

Test Scenarios

1. Open AI Chat Panel

✓ Blue FAB button visible in bottom-right corner
✓ Click opens chat panel with "SahabahGraph Assistant" header
✓ Input field says "Ask about Sahabah or command the graph..."

2. Simple Clear Command

clear the canvas
✓ AI responds with JSON command (you'll see it execute)
✓ Graph canvas clears
✓ No visible nodes remain

3. Add Single Person

show me Abu Bakr
✓ AI returns add command
✓ Abu Bakr node appears on graph
✓ Node is highlighted/focused

4. Add Multiple People

add Umar and Ali to the graph
✓ AI returns multi-add command
✓ Both Umar ibn al-Khattab and Ali ibn Abi Talib appear
✓ Relationship connections visible if they exist

5. Focus Command

focus on Uthman
✓ AI returns focus command
✓ Uthman ibn Affan node is highlighted
✓ Camera zooms/centers on that node

6. Q&A - Historical Information

Who was Abu Bakr?
✓ AI responds with TEXT (not JSON command)
✓ Response mentions: First Caliph, companion of Prophet
✓ Response uses SahabahGraph Assistant identity

7. Q&A - Battle Information

Tell me about the Battle of Badr
✓ AI responds with historical facts
✓ Mentions year 624 CE
✓ Contextually relevant to SahabahGraph data

8. AI Identity Check

What can you do?
✓ AI identifies as "SahabahGraph Assistant"
✓ Lists capabilities: clear, add, focus, search, zoom, view
✓ Does NOT say "I am created by OpenAI"

9. Unsupported Command

draw a circle
✓ Error message shown (not crash)
✓ Suggests alternative like "add" command
✓ Chat remains functional

10. Multi-Command

clear the graph then add Muhammad and Abu Bakr
✓ AI returns JSON with multiple actions
✓ Canvas clears first
✓ Then both nodes appear
✓ Executes in sequence

11. Parser Edge Cases (Internal)

Check browser console for:
✓ No JSON parse errors
✓ Parser steps show (🔍, ✅, etc.)
✓ Nested JSON with brackets/braces handles correctly
✓ Markdown wrapped responses unwrap properly
